# CS2 工具箱 · HLAE 命令

一个用于生成和复制 CS2 / HLAE 命令的单文件网页。主网页是 `index.html`，可直接用浏览器打开，无需安装网页依赖。

## 开始使用

1. 通过 HLAE 启动 CS2，打开要操作的 demo，并启用游戏开发者控制台。
2. 在浏览器中打开 `index.html`，选择功能并调整参数。
3. 点击卡片中的**复制命令**，将命令粘贴到游戏控制台并执行。
4. 使用 HLAE 相机时，关闭控制台后再操作相机。

网页只生成和复制命令，不会自动控制游戏。带开关的功能都提供两个复制入口：主按钮复制开启命令，卡片右上角的**关闭 / 恢复**按钮点击一次即复制对应的关闭命令，无需先切换到关闭状态再复制。参数调整和预览也不会自动同步到游戏；其他卡片右上角的重置按钮同样是**复制重置命令**。

如果浏览器禁止复制，可手动选中命令栏中的文字复制；较长命令可在命令栏内横向滚动。页面支持随设备切换明暗主题。

## 功能速览

### 相机控制

- **HLAE 相机**：主按钮复制 `mirv_input camera` 进入相机模式；右上角“关闭”直接复制 `mirv_input end`；也可按 Esc 退出。
- **重置相机横滚**：将相机画面倾斜归零。
- **相机移动与转向**：调整键盘移动灵敏度、鼠标转向灵敏度，以及位置和转向平滑。一次复制全部设置，命令会启用平滑、鼠标按键移动并进入相机模式；其中 FOV 平滑固定为 0.4 秒。平滑值越大，响应延迟通常越明显。

该卡片的重置命令恢复相关灵敏度及平滑配置、关闭平滑和鼠标按键移动，但不会退出相机模式，也不会还原以前单独修改过的各方向基础速度。

### 关键帧与路径

- **添加关键帧**：记录当前时间、相机位置、朝向及 FOV。同一时间已有关键帧时可能被覆盖。
- **删除指定序号关键帧**：先用卡片内的查看命令获取 ID，再填写 ID 并复制删除命令。
- **删除所有关键帧**：先取消选择，再清空路径。此操作不可撤销。
- **沿关键帧路径运镜**：开启命令先退出相机控制，再启用路径；右上角“关闭”直接复制 `mirv_campath enabled 0` 停止路径覆盖。
- **关键帧与路径显示**：显示或隐藏路径可视化，不等同于开启路径播放；右上角“关闭”直接复制隐藏命令。
- **保持路径首尾画面**：开启后，在路径时间范围前后分别保持首帧和末帧视角；右上角“关闭”直接复制关闭命令。

#### 一条路径的基本流程

1. 在 demo 中进入相机模式，移动到所需位置并调整视角。
2. 在不同时间点添加关键帧。默认插值通常需要至少四帧才能计算路径。
3. 如需记录不同 FOV，添加各帧前分别调整相机 FOV；可用 `mirv_campath print` 检查帧列表。
4. 若之前使用过第一人称 FOV 覆盖，可先执行 `mirv_fov default`，以免覆盖路径的 FOV。
5. 使用“沿关键帧路径运镜”的开启命令，回到首帧之前并播放 demo。

关键帧记录时间、位置、旋转和 FOV；**不记录景深、手臂模型位置或击杀信息设置**。调整相机移动平滑也不会改写路径插值。

### 关键帧位置修改

1. 将相机移动到目标位置，使用查看命令找到目标帧 ID。
2. 填入 ID，复制并执行第一步的选择命令，然后查看控制台输出。
3. **确认只有目标帧被选中**，再勾选确认框，复制并执行第二步的位置修改命令。

> 如果没有选中任何关键帧，位置修改会作用于整条路径。不要跳过控制台确认；第二步执行后会取消选择。

### FOV 视角

- **第一人称视野 FOV**：使用 `mirv_fov` 覆盖镜头视野，也可能影响其他游戏镜头；默认勾选 `mirv_fov handleZoom enabled 1` 以避免覆盖武器开镜视野（取消勾选则会设为 `0`）。重置按钮复制 `mirv_fov default`，取消该覆盖。
- **调整相机 FOV**：使用 `mirv_input fov` 调整 HLAE 相机模式的视角；重置按钮复制将其设为 90 的命令。

重置不会修改已保存的关键帧 FOV。路径播放、FOV 覆盖和相机控制可能互相影响；播放路径时应退出相机模式，并按需要取消 `mirv_fov` 覆盖。

### 手臂模型

**手臂模型位置**使用 HLAE 的 `mirv_viewmodel` 调整第一人称手臂及武器的 X、Y、Z 偏移。应用时模型 FOV 和持枪手使用游戏值；重置按钮复制 `mirv_viewmodel enabled 0`，关闭 HLAE 模型覆盖，包括其他通过该功能设置的覆盖。

### DOF 景深

- 在二维视锥内拖动绿色清晰区域或两端手柄，也可直接输入清晰范围的起点和终点；选中手柄后可用方向键微调。
- 绿色代表清晰区域，橙色代表模糊区域。预览是示意图，不代表实际 FOV 或游戏最终渲染效果。
- 边界自动留出 1 游戏单位过渡；可另外调节实验性的模糊上限。
- 主按钮复制开启及调整景深的命令；右上角“关闭”直接复制关闭命令：关闭景深覆盖，并将模糊上限设为参考值 5，不会恢复其先前自定义值，也不影响 ReShade。

景深覆盖需要允许 `sv_cheats 1` 的环境，例如本地练习；不能用于普通竞技服务器。实验性变量需要 HLAE 解锁，实际效果可能随游戏版本变化。

### 比赛结束画面

- **比赛结束画面**：主按钮复制隐藏命令；右上角“恢复”直接复制恢复命令。
- **赛末统计**：主按钮将面板透明度设为 0；右上角“恢复”直接复制设为 1 的命令。需要 HLAE 2.187.6 或更新版本；重新加载 demo 后需重新应用。恢复设为 1，不一定还原之前的自定义透明度。

### 击杀信息

- **颜色**：调整 CT / T 玩家文字、普通背景、本地玩家背景和边框；0 为透明，255 为不透明。预览仅供参考，复制颜色设置会同时应用五项。恢复默认按钮会复制五项默认命令。
- **清除击杀信息**：清除当前显示的击杀通知。
- **显示时长**：设置新通知的显示秒数，并提供恢复默认命令。本地玩家通知还可能受时长倍率影响。

## 注意事项

- 输入框中的值是网页当前值，不会读取游戏内设置。重置按钮复制命令，不会把网页控件同步为游戏状态。
- 命令和游戏效果可能随 CS2 或 HLAE 更新变化。
- 已有自定义配置可能影响结果，尤其是之前设置过的相机速度、FOV 覆盖或模型覆盖。
