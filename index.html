HLAE / CAMERA

HLAE 命令

常用命令，一键复制。粘贴到 CS2 控制台即可使用。卡片右上角的「关闭 / 恢复」按钮会直接复制对应的关闭命令，无需先切换再复制。

相机控制

03 CARDS

HLAE 相机

进入相机控制模式，自由调整视角；也可按 Esc 退出。

>_mirv_input camera

重置相机横滚

在 HLAE 相机模式下，将 Z / X 造成的画面倾斜归零；保留俯仰和朝向。

>_mirv_input angles * * 0

相机移动与转向

设置移动和转向参数，应用后进入相机模式。

>_

关键帧与路径

06 CARDS

添加关键帧

将当前时间和视角添加到相机路径。

>_mirv_campath add

删除指定序号关键帧

先复制并运行查看命令，填入要删除的帧 ID。

>_mirv_campath remove <ID>

删除所有关键帧

先取消帧选择，再清空全部关键帧。

>_mirv_campath select none; mirv_campath clear

沿关键帧路径运镜

退出相机控制并启用路径；回到首帧之前播放 demo。

默认插值通常需要至少四帧；FOV 覆盖可能影响路径视角。

>_mirv_input end; mirv_campath enabled 1

关键帧与路径显示

在场景中显示关键帧与相机运动曲线。

>_mirv_campath draw enabled 1

保持路径首尾画面

路径开始前和结束后，分别保持首帧和末帧视角。

>_mirv_campath hold 1

关键帧位置修改

01 CARD

修改指定关键帧的位置

把相机移到目标位置，先查看并选择帧 ID。

第一步：选择该帧并打印列表，确认只有目标帧被选中。

>_mirv_campath select #ID #ID; mirv_campath print

注意：如果没有选中任何帧，位置命令会修改整条路径！

>_mirv_campath edit position current; mirv_campath select none

第二步：将选中帧移到当前相机位置，然后取消选择。

FOV 视角

02 CARDS

第一人称视野 FOV

调节观察玩家时的视野，也会覆盖其他游戏镜头的 FOV。

>_mirv_fov 90; mirv_fov handleZoom enabled 1

已勾选时开镜保留武器缩放视野；播放路径前建议先取消 FOV 覆盖。

调试 FOV 重置可能需要允许作弊，不会修改武器模型 FOV。

调整相机 FOV

调节 HLAE 相机模式的视角；输入或拖动滑块后复制命令。

>_mirv_input fov 90

重置为 90，需在相机模式中执行。

手臂模型

01 CARD

手臂模型位置

调整第一人称手臂及武器的水平、前后和上下位置。

FOV 和持枪手随游戏设置；重置会关闭 HLAE 模型覆盖。

>_mirv_viewmodel set 1 1 -1 * *; mirv_viewmodel enabled 1

DOF 景深

01 CARD

自定义景深

在视锥内拖动绿色区域，或拖动两端手柄调整清晰范围；距离单位为游戏单位。

景深范围 · 俯视示意
清晰模糊
相机 · 0

可拖动绿色范围整体移动，也可拖动两端；选中手柄后可用方向键微调。数值框可精确输入，预览距离只改变图示比例，不小于清晰终点。

图示为简化效果：清晰范围以外设为模糊，边界自动留 1 游戏单位过渡；实际模糊程度受模糊上限和游戏渲染影响，视锥角度不代表当前 FOV。

右上角“关闭”会直接复制关闭命令：关闭景深覆盖并将模糊上限设为 5，不影响 ReShade；该变量需 HLAE 解锁，效果可能因版本而异。

>_mirv_cvar_unhide_all; r_dof_override 1; r_dof_override_near_blurry -1; r_dof_override_near_crisp 0; r_dof_override_far_crisp 180; r_dof_override_far_blurry 181; r_dof2_maxblursize 5

比赛结束画面

02 CARDS

比赛结束画面

隐藏 demo 中的比赛结束画面。

>_mirv_endofmatch 0

赛末统计

隐藏赛末统计面板。

需要 HLAE 2.187.6 或更新版本；右上角“恢复”直接复制将透明度设为 1 的命令，重新加载 demo 后需重新设置。

>_mirv_panorama panelStyle panelId=EndOfMatch opacity=0

击杀信息颜色

分别设置 CT / T 玩家名称、背景和本地玩家高亮的颜色与透明度。

0 为透明，255 为不透明；颜色设置会同时覆盖以上五项。

>_

清除击杀信息

清除屏幕上当前显示的击杀通知。

>_mirv_deathmsg clear

击杀信息显示时长

设置新击杀通知的显示秒数。

滑块为 0～120 秒，输入框可填至 3600 秒；本地玩家通知还可能受时长倍率影响。

>_mirv_deathmsg lifetime 6

使用前请通过 HLAE 启动 CS2。相机命令执行后需关闭控制台才能操作。景深覆盖需允许 sv_cheats 1（如本地练习环境）；不可用于普通竞技服务器。删除全部关键帧不可撤销，请谨慎操作。
